# 开发日志（devlog）

对齐 **RepoAgent** 习惯：本目录是项目的时间线真相源。时区：**Asia/Shanghai**。

## 目录结构

```
docs/devlog/
  README.md           # 本文件：规范 + 索引
  daily/YYYY-MM-DD.md # 日报
  monthly/YYYY-MM.md  # 月报
```

## 维护规则

在每轮**实质性工作结束前**必须完成：

1. **追加**当天 `daily/YYYY-MM-DD.md` 的工作明细（可多次追加，不要只改摘要）
2. **更新**该日报顶部的「当日摘要」
3. **同步**当月 `monthly/YYYY-MM.md`（状态、风险、下月重点）
4. **更新**本 README 底部的索引表（链接 + 一句话）

### 日报模板

```markdown
# YYYY-MM-DD

## 当日摘要
（3–5 句，可被索引引用）

## 工作明细

### 条目标题
- **目标**：
- **讨论与操作**：
- **结果与验证**：
- **相关产物**：（路径）
- **待办**：
```

### 月报模板

```markdown
# YYYY-MM 月报

## 本月概要

## 里程碑状态

## 风险与阻塞

## 下月重点
```

### 写作约束

- 不把**计划**写成**已完成**；未跑通的验证不写「已通过」
- 不写密钥、token、`.env` 内容
- 不贴完整聊天纪录；可摘决策要点
- 与根目录 [AGENTS.md](../../AGENTS.md) 规则一致（代理必读）
